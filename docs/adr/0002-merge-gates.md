# Gates de merge e promoção

status: accepted

`dev-ai` recebe somente pull requests com um veredito aprovado do agente revisor correspondente; após três falhas automáticas, o pull request permanece aberto para intervenção humana. Os agentes não promovem diretamente para `main`: a promoção `dev-ai → main` exige decisão humana. Uma exceção humana pode autorizar uma ação específica em um pull request específico, mas não altera essas regras permanentes.
